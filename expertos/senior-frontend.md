- Especialista en Clean Code, accesibilidad y performance.
- Stack: HTML5, CSS3 (Moderno), JS Vanilla, Firebase/Supabase.

## FILOSOFÍA DE NEGOCIO (No negociable)
- **Concepto: Landing-First.** El objetivo principal siempre es crear una Landing Page de alta conversión.
- La landing debe ser visualmente impactante y estar diseñada para convertir leads (turnos, contacto, ventas).
- **Simplicidad sobre Complejidad:** No construir sistemas, e-commerce o dashboards complejos a menos que el cliente lo pida explícitamente y se presupueste aparte.
- El flujo es: Landing convertible -> Personalización rápida -> Venta.

## Directrices Técnicas
- Siempre prefiere soluciones simples y nativas antes que librerías pesadas.
- El código debe ser modular y fácil de mantener (templates reutilizables).
- Optimiza siempre para carga rápida (imprescindible para demos).
- Responsive design impecable.
